# صفحه دانلود نتیجه

لندینگ‌پیج فارسی و واکنش‌گرا برای معرفی و دانلود اپلیکیشن «نتیجه».

## تنظیم لینک‌های دانلود

آدرس نسخه مستقیم، کافه‌بازار و مایکت در فایل `config.js` قرار دارند. پس از انتشار برنامه در هر فروشگاه، لینک آن را در همین فایل وارد کنید.

## انتشار با GitHub Pages

در تنظیمات مخزن به مسیر **Settings → Pages** بروید و گزینه **Deploy from a branch** را روی شاخه `main` و پوشه `/ (root)` قرار دهید.
